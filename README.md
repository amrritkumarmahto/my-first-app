# Money Tracker

A simple web app for tracking income, expenses, and savings, with support
for international currencies. Built as my first app with Claude Code.

## Current status

**Stage 1: layout only.** The page shows the app's structure (summary cards,
a space for the transaction form, the transaction list, and a chart area).
Nothing is interactive yet, and no currency has been chosen: amounts are
shown as "—" until the currency system is added in a later stage.

## How to open the app

No installation is needed.

1. Download or clone this repository to your computer.
2. Open the folder and double-click `index.html`.
3. It opens in your web browser (Chrome, Firefox, Safari, or Edge).

## Files

| File         | What it does                                        |
|--------------|-----------------------------------------------------|
| `index.html` | The page structure: header, cards, and sections     |
| `style.css`  | Colours, spacing, and the mobile/desktop layout     |
| `app.js`     | The app's logic (almost empty in Stage 1)           |

## Built with

Plain HTML, CSS, and JavaScript. No frameworks or packages.
